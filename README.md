Multi-Step Form

A simple and responsive Multi-Step Form built using HTML, CSS, and JavaScript.

Features

- Step-by-step form navigation
- Personal and contact information fields
- Form validation
- Progress bar to track current step
- Previous and Next buttons
- Final summary before submission
- Saves form data using Local Storage
- Responsive and clean user interface

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Use

1. Enter your personal information.
2. Fill in your contact information.
3. Select a course and write a message.
4. Review your information in the final summary.
5. Click Submit to complete the form.

Project Structure

- "index.html" — Form structure
- "style.css" — Styling and layout
- "script.js" — Form functionality and validation

What I Learned

Through this project, I practiced DOM manipulation, form validation, event handling, Local Storage, and creating a multi-step form using JavaScript.
